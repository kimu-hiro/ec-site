# 06 画面遷移図を作る（マスト）

## 何のためか

05 のページ一覧は「部屋の一覧」だった。
06 の画面遷移図は、部屋と部屋をつなぐ**廊下の地図**。
「どのページで、何をすると、どのページへ行くか」を
箱と矢印で描く。

- 遷移 ＝ うつりかわること。ページからページへ移ること
- 新しく覚えること：Excel で図形（箱と矢印）を描く
- 新しく入れるもの：無い（Excel はもう入っている）

## できあがりの形

```
ECsite/
  └ 書類リスト/
      ├ 課題チェックリスト.md
      ├ 01_ページ一覧.md
      ├ 02_画面遷移図.xlsx   ← 描く所（git には入れない）
      └ 02_画面遷移図.png    ← 完成品のスクショ（git に入れる）
```

## 1. どこからどこへ行くかを、先に書き出す

いきなり描かない。先に「廊下」を全部集める。

`書類リスト/課題チェックリスト.md` を開いて、`⌘F` で
次の言葉を1つずつ探す。

| 探す言葉 | 見つかるもの |
|---|---|
| `遷移` | ページを移る所 |
| `リンク` | ほかのページへのリンク |
| `リダイレクト` | 自動で別のページへ送られる所 |
| `ログアウト` | ログインページへもどる所 |

見つけた行を、メモ（紙でも、どこかの md でもよい）に
この形で書き出す。

```
どこから → どこへ（何をしたとき）
```

例（チェックリストの最初の方にある行から）：

```
ログイン → 商品一覧（ふつうのユーザーでログイン）
ログイン → 商品管理（管理用ユーザーでログイン）
```

- 「ログインしていないとき、ログインページへ」の行は、
  ページごとに何回も出てくる。1つずつ全部書き出す
- 書き出せたら、Claude に見せてもよい
  （描く前に抜けが分かるので、描き直しがへる）

## 2. Excel の新しいファイルを作る

Excel を開いて、空のブックを作る。
`書類リスト/02_画面遷移図.xlsx` という名前で保存する。

- ブック ＝ Excel のファイル1つのこと
- ファイル名は、05 と番号をそろえて `02_` から始める

## 3. 箱を6つ置く

メニューの「挿入」→「図形」→ 四角形を選び、
シートの上をドラッグして箱を描く。

- 箱をクリックして、そのまま文字を打つと、箱の中に文字が入る
- 1つ描けたら、`⌘C` → `⌘V` で増やすと、大きさがそろう

箱の中には、05 で決めた**名称**と**ファイル名**を書く。

```
ログイン
index.php
```

置き方のヒント：

- ログイン（トップページ）を一番上に置く
- お客さんの流れ（商品一覧 → カート → 購入完了）を
  たてに並べると、読む人が上から順に追える
- 商品管理は、お客さんの流れの横に、はなして置く

## 4. 矢印でつなぐ

「挿入」→「図形」→ 線の中の矢印を選び、
箱から箱へドラッグする。

- 箱のふちに近づけると、点が出る。そこに矢印の端を
  くっつけると、あとで箱を動かしても矢印がついてくる
- 矢印の横に「何をしたとき」を書く。
  「挿入」→「テキストボックス」で文字を置く

1 で書き出したメモを上から1つずつ描き、
描いたものに線を引いていく。

## 5. スクショを撮る

見せたくない物が画面に写っていないかを、先に見る。
（01 の段で、パスワードが写った画像を貼ってしまったため）

`⌘` + `shift` + `4` を押して、図の所をドラッグで囲む。
デスクトップに画像ができる。

- `⌘` + `shift` + `4` ＝ 囲んだ所だけスクショする

できた画像の名前は
`スクリーンショット 2026-11-19 14.20.00.png` のように
空白が入っている。空白の入った名前は、ターミナルで
あつかいにくいので、`02_画面遷移図.png` に名前を変えて、
`書類リスト/` に入れる。

## 6. Claude に見せる

画像をチャットに貼るか、「書類リストに入れた」と伝える。
Claude は次を一緒に見る。

- 6ページの箱が全部あるか
- 1 で書き出した廊下が、全部矢印になっているか
- 矢印の向きと、「何をしたとき」の文字が合っているか

## 7. git に入れる

Excel のファイルは git に入れない、と決めたので、
先に `.gitignore` に足す。
（何をどう書くかは、自分で考えてみる。
ヒント：`.gitignore` には、ファイル名のかわりに
`*`（何でもよい、の印）を使った書き方もできる）

足せたら、次で確かめる。

```bash
git status
```

`02_画面遷移図.png` は出て、`02_画面遷移図.xlsx` は
出なければ OK。

```bash
git add .gitignore 書類リスト/02_画面遷移図.png
git commit -m "画面遷移図を作る"
git push
```

## つまずいたら

| 出たもの | 意味 | 直し方 |
|---|---|---|
| 箱を動かすと矢印が離れる | 矢印の端が箱にくっついていない | 箱のふちの点に、矢印の端を合わせ直す |
| `git status` に `.xlsx` が出る | `.gitignore` の書き方が合っていない | 書いた行を Claude に見せる |
| スクショがどこにあるか分からない | ふつうはデスクトップ | Finder の「最近の項目」を見る |
