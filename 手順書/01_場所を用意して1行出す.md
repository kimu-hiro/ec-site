# 01 場所を用意して、ブラウザに1行出す

## 何のためか

家を建てる前に、土地に杭を1本打つ段。
「自分の PHP のファイルが、ブラウザで開ける」ことだけを確かめる。
ここができれば、あとは中身を足していくだけになる。

- 新しく覚えること：PHP に付いている小さなサーバーの起動
- 新しく入れるもの：無い

## できあがりの形

```
ECsite/
  ├ 手順書/          （これ）
  └ htdocs/
      └ ec_site/
          └ index.php   ← 今日作るのはこれだけ
```

- `htdocs/ec_site/` は、課題で決められている置き場所
- `index.php` は、課題で決められているトップページの名前
- htdocs ＝ hypertext documents
  （hypertext＝リンクでつながる文書、documents＝文書）。
  ブラウザに見せるファイルの置き場、という意味

## 1. フォルダを作る

ターミナルで、ECsite に移動してから打つ。

```bash
cd ~/development/ECsite
mkdir -p htdocs/ec_site
```

- `mkdir` ＝ make directory ＝ フォルダを作る
- `-p` ＝ parents（親）＝ 途中のフォルダ（`htdocs`）も
  無ければ一緒に作る

確かめ方：

```bash
ls htdocs
```

`ec_site` と出れば OK。

## 2. index.php に1行だけ書く

VS Code で `htdocs/ec_site/index.php` を作り、次の2行を書く。

```php
<?php
echo 'EC サイト、はじめの1行';
```

- `<?php` ＝ 「ここから PHP ですよ」の合図
- `echo` ＝ 画面に出す、の命令（シェルの `echo` と同じ役目）
- 行の終わりの `;` ＝ 「この命令はここまで」の印

小ネタ：PHP だけのファイルでは、終わりの合図 `?>` を書かない。
終わりの合図のあとに空白がまぎれると、あとで
「もう送ってしまった」というエラーのもとになるため。
（きりたんの回の `headers already sent` の話）

## 3. 小さなサーバーを起動する

ECsite のフォルダにいることを確かめてから打つ。

```bash
pwd
php -S localhost:8000 -t htdocs
```

- `pwd` ＝ print working directory ＝ 今いる場所を出す。
  `/Users/kimuhiro/development/ECsite` と出れば OK
- `php -S` の `-S` ＝ Server ＝ PHP に付いている
  小さなウェブサーバーを起動する（大文字の S）
- `localhost:8000` ＝ 自分の Mac の、8000 番の入口で待つ
- `-t` ＝ target（まと）＝ どのフォルダを外に見せるか。
  ここでは `htdocs`

うまくいくと、こういう行が出て、そのまま止まって見える。

```
PHP 8.5.12 Development Server
(http://localhost:8000) started
```

止まって見えるのは、注文を待っているから。こわれていない。
このターミナルは、開いたままにする。

なぜ Apache を使わないのか：
Mac の Apache は、今は DAM のフォルダを外に見せている。
EC サイト用に変えると、DAM が見られなくなる。
PHP の小さなサーバーなら、設定を何も変えずに、
1行で起動できる。

注意：この小さなサーバーは、作っている間に試すためのもの。
本当のお店（本番）で使うものではない、と PHP の公式も書いている。

## 4. ブラウザで確かめる

ブラウザで、次を開く。

```
http://localhost:8000/ec_site/
```

`EC サイト、はじめの1行` と出れば、この段は成功。

ターミナルの方にも、注文が来た記録が1行ふえる。
`[200]` は「うまく返せた」の番号。

## 5. 中身を変えて、もう一度見る

`index.php` の文字を好きに変えて、保存する。
ブラウザを再読み込みして、変わっていれば OK。

サーバーを起動し直さなくても変わる、ということを
ここで体で確かめておく。

## 6. サーバーを止める

サーバーのターミナルで `control` + `C` を押す。

確かめ方：ブラウザを再読み込みして、
「このサイトにアクセスできません」と出れば、止まっている。

次に作業するときは、手順 3 のコマンドでまた起動する。

## つまずいたら

| 出たもの | 意味 | 直し方 |
|---|---|---|
| `Address already in use` | 8000 番の入口を、もう何かが使っている | 前に起動したサーバーが残っている。そのターミナルで `control` + `C`。見つからなければ、番号を `8001` に変えて起動する |
| ブラウザに `Not Found` | そのファイルが見つからない | 住所が `/ec_site/` か、起動した場所が ECsite か（`pwd`）、`-t htdocs` を付けたかを見る |
| `Directory htdocs does not exist` | `htdocs` が見つからない | 今いる場所が ECsite ではない。`cd ~/development/ECsite` してから起動する |
| 画面に `<?php echo ...` がそのまま出る | PHP として動いていない | ファイルの名前の終わりが `.php` か、1行目が `<?php` かを見る |
| `Parse error: syntax error` | 書き方のまちがい | エラー文の `on line 2` の数字が行番号。`;` や `'` の閉じ忘れが多い |
| 画面がまっ白 | 何も出していない。または、PHP として動いていない | `echo` の行があるか、保存したかを見る。それでも白ければ、画面を右クリック →「ページのソースを表示」。自分の PHP のコードがそのまま見えたら、PHP として動いていない（1つ上の行の直し方を見る） |

ここに無いものが出たら、エラー文をそのまま Claude に貼る。
