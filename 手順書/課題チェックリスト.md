# 課題チェックリスト

## 提出要件
- [ ] Redmineにて完了報告・チェックの依頼をする
- [ ] ソースコードを最新の状態でGitHubにcommit、pushしているか
- [ ] 後述の「書類一式」をzip形式で圧縮して、Redmineのチケットに添付しているか
- [ ] 書類一式がマストのみ、か、ベターまで作成したかを明記しているか
- [ ] 自分でで考えた機能の仕様の説明を付与しているか


## 実装要件
- [ ] TRY57で使用したincludeディレクトリと配下のディレクトリを利用し、MVCモデルを利用したディレクトリ構成になっているか
- [ ] ユーザーが直接アクセスするcontrollerはhtdocs/ec_site/というディレクトリを作成して格納しているか
- [ ] トップページのファイル名はindex.phpになっているか
- [ ] ファイルの呼び出し・リンク・フォームのactionなどURLを指定する際は絶対パスではなく相対パスで記述しているか
- [ ] 複数回使用する処理、類似の処理については関数にまとめられているか
- [ ] データベース接続情報などのプログラム上で変更が行われない値は定数として指定しているか
- [ ] 定数は、includeディレクトリ直下（model、viewと同じ階層）に/config/というフォルダを作成し、その下にconst.phpというファイルを作成しそのファイル内にまとめられているか
- [ ] データベースは正規化され、外部キー制約が適切に行われているか
- [ ] バリデーション（入力チェック）はフロントエンド・サーバーサイド両方で行われているか
- [ ] フロント側の実装はHTMLのフォームのチェック機能、もしくはJavaScriptで、全て一律で同じようにエラーメッセージが表示されるか
- [ ] XSS・SQLインジェクションに配慮した実装となっていること。
- [ ] バリデーションにおけるエラーメッセージには、入力値の何が問題かがユーザーに分かる内容で記述されているか
- [ ] ヘッダー等の共通化して使用できる画面パーツについては、PHPでテンプレート化が行われているか
## デザイン・文言について
- [ ] 画像などを使用する場合は無料画像や著作権的に使用が問題がないか

## ページごとの要件詳細
### ログインページ（トップページ）
- [ ] ユーザー名とパスワードの二つのinputformを実装できているか
- [ ] ユーザー名欄の入力が問題なくおこなえるか
- [ ] パスワード欄の入力が問題なくおこなえるか
- [ ] ユーザー名欄のバリデーション、placeholderの設定はできているか
- [ ] パスワード欄のバリデーション、placeholderの設定はできているか
- [ ] ユーザー名欄のXSS対策ができているか
- [ ] パスワード欄のXSS対策ができているか
- [ ] 登録されているユーザー名を正しく認証できているか
- [ ] 登録されているパスワードを正しく認証できているか
- [ ] 「ログイン」ボタンをクリック時、データベースに登録されているユーザーと入力された「ユーザー名」と「パスワード」が一致したとき、「商品一覧」ページに遷移するか
- [ ] 事前にデータベースに登録している管理用ユーザー（ID：ec_admin ,パスワード：ec_admin）でログインした場合、管理側の「商品管理」ページに遷移するか
- [ ] 一致しないユーザー名、パスワードで認証しようとした時、ログインを弾けているか
- [ ] 登録されていないユーザー名やパスワードで認証しようとした時、"ユーザー名、もしくはパスワードが間違っています"と赤い文字でエラ〜メッセージが表示されるか
- [ ] 「ログイン」ボタン押下時、データベースに登録されているユーザーと入力された「ユーザー名」と「パスワード」が一致しない時にはログインをさせず、ページ遷移も行わない。処理の巻き戻し(ロールバック)ができているか。
- [ ] 半角数字とアルファベット以外のものを入力して認証しようとした時、"半角数字、アルファベットを入力してください"と赤い文字でエラーメッセージが出るか
- [ ] 「ユーザー登録」ページへのリンクを作っているか
- [ ] 「ユーザー登録」ページへのリンクから遷移する事ができるか

### ユーザー登録ページ：ユーザーの登録を行う
- [ ] 「ユーザー名」「パスワード」を入力する項目を表示する。
- [ ] 「登録」ボタンをクリック時、入力された「ユーザー名」「パスワード」をデータベースに保存し、登録完了メッセージを表示する。
- [ ] 「ユーザー名」は「５文字以上」かつ「半角英数字とアンダースコア（_）」のみ登録可能。それ以外の場合、エラーメッセージを表示し、登録を行わない。
- [ ] 「パスワード」は「８文字以上」かつ「半角英数字とアンダースコア（_）」のみ登録可能。それ以外の場合、エラーメッセージを表示し、登録を行わない。
- [ ] ユーザーを追加する場合、既に同じ「ユーザー名」が登録されている場合、エラーメッセージを表示し、登録を行わない。
- [ ] 「ログイン」ページへ遷移する事ができる。
- [ ] ログインされている状態でアクセスした場合「商品一覧」ページにリダイレクトされる。

### 商品管理ページ
- [ ] 「商品名」「値段」「在庫数」「公開ステータス」「商品画像」を入力し、商品を追加できる。
- [ ] 追加した商品の「商品画像」「商品名」「値段」「在庫数」「公開ステータス」のデータを一覧で表示する。
- [ ] 一覧から指定した商品の在庫数を変更することができる。
- [ ] 一覧から指定した商品の公開フラグを「公開」「非公開」に変更することができる。
- [ ] 一覧から指定した商品の削除をすることができる
- [ ] 「商品追加」ボタンクリック時、「商品名」「値段」「在庫数」「公開ステータス」「商品画像」が設定されていない場合、エラーメッセージを表示し、商品を追加しない。
- [ ] 商品を追加する場合、「値段」「在庫数」は0以上の整数のみ可能。それ以外の場合、エラーメッセージを表示し、商品を追加しない。
- [ ] 投稿できる商品画像の形式は「JPEG」「PNG」のみとする。「JPEG」「PNG」以外の場合、エラーメッセージを表示し、商品を追加しない。
- [ ] 一覧から在庫数を変更する場合、0以上の整数のみ可能とする。0以上の整数以外はエラーメッセージを表示して、変更できない。
- [ ] 商品の追加、指定商品の在庫数、公開フラグの変更が正常に完了した場合、完了メッセージを表示する。
- [ ] ログアウトすることができる。ログアウト時、「ログイン」ページへ遷移する。
- [ ] ログインしていない状態で「商品管理」ページへアクセスした場合、「ログイン」ページへ遷移する。

### 商品一覧ページ
- [ ] 商品のステータスが「公開」の商品の「商品名」「値段」「商品画像」を一覧で表示する。
- [ ] 商品の在庫が0の場合、「カートに入れる」ボタンは表示しない。「売り切れ」と表示する。
- [ ] 「カートに入れる」ボタンをクリックした場合、指定商品をDBのショッピングカート情報を保存するテーブルに保存する。正常にカートに保存されたメッセージを表示する。
- [ ] 「カートに入れる」ボタンをクリックした場合、指定商品がすでにDBのショッピングカート情報を保存するテーブルに保存されている時、DBの数量をDBの数量＋１に更新する。
- [ ] 「ショッピングカート」ページへ遷移することができる。
- [ ] ログアウトすることができる。ログアウト時、「ログイン」ページへ遷移する。
- [ ] ログインしていない状態で「商品一覧」ページへアクセスした場合、「ログイン」ページへ遷移する。

### ショッピングカートページ
- [ ] ショッピングカートに入れた商品の「商品画像」「商品名」「値段」「数量」を表示する。表示するカート情報はDBを参照します。
- [ ] ショッピングカート内にある商品の小計金額を表示する。
- [ ] 指定の商品をDBのショッピングカート情報を保存するテーブルから削除することができる。
- [ ] 指定商品の数量を変更することができる。変更時の数量はDBの数量を更新することで保存する。
- [ ] 指定商品の数量を変更する場合、正の整数のみ可能。それ以外はエラーメッセージを表示し、変更できない。
- [ ] 「商品一覧」ページに遷移することができる。
- [ ] 「購入する」ボタンをクリックした場合、「購入完了」ページへ遷移する。
- [ ] 指定商品がカートに入っている間に、他のユーザーが同じ商品を決済し在庫切れになった場合、決済時に「在庫がなくなった」という旨のエラーを表示させる。（2022/08/02追加要件）
- [ ] ログアウトすることができる。ログアウト時、「ログイン」ページへ遷移する。
- [ ] ログインしていない状態で「ショッピングカート」ページへアクセスした場合、「ログイン」ページへ遷移する。

### 購入完了ページ
- [ ] 購入した商品の「商品画像」「商品名」「値段」「数量」を表示する。表示するカート情報はDBを参照します。
- [ ] 購入した商品の小計金額を表示する。
- [ ] 購入した商品の在庫数を、購入数減らす。
- [ ] ショッピングカートに入れた商品の情報をDBから削除する。
- [ ] 「商品一覧」ページに遷移することができる。
- [ ] ログアウトすることができる。ログアウト時、「ログイン」ページへ遷移する。
- [ ] ログインしていない状態で「購入完了」ページへアクセスした場合、「ログイン」ページへ遷移する。
