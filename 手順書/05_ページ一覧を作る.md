# 05 ページ一覧を作る（マスト）

## 何のためか

お店の案内板を作る段。
「このお店には、どんな部屋が、どこに、何のためにあるか」を
1枚の表にする。
作る前に部屋の数と名前を決めておくと、
06 の画面遷移図も、13 から先のコードも、この表を見て進められる。

- 新しく覚えること：Markdown の表の書き方
- 新しく入れるもの：無い
- 課題で必ず入れる列：**URL・名称・概要** の3つ

## できあがりの形

```
ec-site/
  ├ 手順書/
  └ 書類リスト/
      ├ 課題チェックリスト.md（04 で作った）
      └ 01_ページ一覧.md   ← 今日作るのはこれ
```

- `書類リスト/` は、書類（05〜08）と課題チェックリストを
  入れる場所。手順書とは分けておく
- 31 の段で zip にするとき、課題チェックリストは
  提出の書類ではないので、入れるかどうかをそこで決める

## 1. お手本を見る（5分だけ）

課題文の書類リストに、こう書いてあった。

```
例：Google画像検索「Webサイト ページ一覧」
```

ブラウザで画像検索して、何枚か見る。
見るのは2つだけ。

- 列（たての並び）に、何が並んでいるか
- 1行に、1ページずつ書いてあるか

全部まねしなくていい。「こういう形か」が分かれば十分。

## 2. ファイルを作る

`書類リスト/` は、もう作ってある。
VS Code で `書類リスト/01_ページ一覧.md` を作り、題名だけ書く。

```markdown
# ページ一覧
```

## 3. 表の頭（見出しの行）を書く

Markdown の表は、`|`（縦の棒）で区切って書く。

```markdown
| URL | 名称 | 概要 |
|---|---|---|
```

- 1行目 ＝ 列の名前
- 2行目 ＝ 「ここまでが見出し」の印。`---` を列の数だけ並べる
- `|` は、Mac では `shift` + `¥` で出る

## 4. 1行目にログインページを書く

ログインページだけは、課題で名前が決まっている（`index.php`）。

```markdown
| URL | 名称 | 概要 |
|---|---|---|
| ec_site/index.php | ログイン | （ここに概要） |
```

URL は `htdocs/` から先を書く。
（サーバーの住所 `https://…/` から全部書くと長すぎるので、
表の上に1回だけ書いておけばよい）

```markdown
URL は、次の住所のあとに付ける。
https://portfolio02.dc-itex.com/tamachi/0008/
```

住所が合っているかは、01 でブラウザに出したときの
URL を見て確かめる。

## 5. 残りの5ページを足す

チェックリスト（`書類リスト/課題チェックリスト.md`）の
「ページごとの要件詳細」の見出しの順に、1行ずつ足す。

| 決めること | ヒント |
|---|---|
| ファイル名 | 半角の英小文字と `_`。中身が分かる名前 |
| 名称 | 課題と同じ名前（「商品管理」など） |
| 概要 | そのページで何ができるかを1文で |

ファイル名の例（このまま使わなくてよい）：

```
cart.php  ← cart ＝ 買い物かご
```

ファイル名は、ここで決めたものを 13 から先でそのまま使う。
あとで変えると、リンクを全部直すことになるので、
少し考えて決める。

## 6. 概要の書き方

チェックリストの、そのページの行を見ながら、
「何ができるページか」だけを短く書く。
細かい決まり（5文字以上など）は書かない。それはチェックリストにある。

例（ログインの場合）：

```
ユーザー名とパスワードでログインする。
管理用ユーザーは商品管理へ、それ以外は商品一覧へ進む
```

## 7. 表になっているか見る

VS Code で `⌘K` を押してから `V` を押すと、
右半分に、表になった形（プレビュー）が出る。

- `⌘K` → `V` ＝ Markdown のプレビューを横に出す
  （2つのキーを順番に押す）
- 表にならず `|` がそのまま見えたら、2行目の `|---|` が
  抜けていないか、列の数がそろっているかを見る

## 8. Claude に見せる

保存して「書けた」と Claude に伝える。Claude は次を一緒に見る。

- 6ページそろっているか
- 名称が課題と同じか
- 概要が、チェックリストの中身と合っているか

## 9. git に入れる

```bash
git add 書類リスト/01_ページ一覧.md
git commit -m "ページ一覧を作る"
git push
```

- `-m` ＝ message ＝ その場で commit の説明を書く

## つまずいたら

| 出たもの | 意味 | 直し方 |
|---|---|---|
| プレビューで表にならない | 表の書き方の印が足りない | 2行目の `\|---\|---\|---\|` があるか、各行の `\|` の数が同じか |
| ファイル名が決められない | ふつう | 仮の名前で書いて、`？` を付けて Claude に聞く |
